# Lawful demo plan

The demo presents one focused, performance-preserving MiniMax H3 recasting
studio. It must use original or fully licensed footage. Do not use film/TV
experiments from private development, and do not describe RecastRoom as a
complete Higgsfield-platform replacement.

## Source plate

Record a 6–8 second shot:

- one performer,
- frontal or three-quarter face,
- eyes visible,
- mouth visible,
- stable camera,
- clear line,
- quiet room,
- no hats or sunglasses.

Suggested line:

```text
Same camera. Same voice. New actor. Open source.
```

Keep signed consent and permission records with the project records.

## Reference photos

Provide two authorized references:

1. frontal chest-up,
2. three-quarter chest-up.

Plain lighting, sharp focus, no sunglasses.

## Demo outputs

The demo should produce:

1. source clip,
2. recast clip,
3. source/final side-by-side,
4. contact sheet,
5. word-timing JSON,
6. QC report,
7. downloadable workflow.

## Sound-design lab

The local `/sound-lab.html` route is an audition surface for the longer demo:

1. brand pulse,
2. soft UI tick family,
3. signature source-to-recast reveal,
4. music bed that resolves under the CTA.

It uses the pinned local MIT-licensed `Tone.js 15.1.22` asset. The lab is an
audio identity tool, not a narration generator; Drama 3 Voice A remains the
demo narrator.

## Public landing v3

The separate `/landing.html` surface is the contest-ready public overview. It
places the frozen v6b keeper in the hero, explains the three-step rights and
review workflow, shows six animated feature stories, and routes visitors to the
local dry run without changing the production workspace.

The landing also includes a three-result proof gallery and a growth path. The
gallery uses existing synthetic keeper comparisons only. Multi-person
selection, scene/effect recipes, and the take queue remain explicitly labeled
roadmap concepts rather than fake ready workflows.

The public page also discloses the runtime boundary:

```text
Dry run: no GPU, no API key, no inference, no provider charge
Local ComfyUI: operator hardware and local endpoint
Official SDK: owner-configured deployment and provider usage
```
