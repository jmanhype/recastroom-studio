# #OpenSourceHiggsfield submission plan

Comfy's Open Source Higgsfield challenge closes **October 30, 2026 at 9:00 AM PT**.

Source: <https://comfy.org/open-source-higgsfield/>

Current official H3 context:
<https://blog.comfy.org/p/comfy-is-now-the-only-official-reseller>.
Wiki summaries, community notes, and prior-challenge judging language are
supporting signals only; they do not amend these requirements.

## Required submission materials

- one focused open-source creative app built on the Comfy Developer Platform,
- GitHub repository,
- open-source license,
- local setup instructions,
- Comfy API-format workflow files,
- demo video no longer than two minutes,
- public social post tagging #OpenSourceHiggsfield,
- optional but encouraged: deployed link people can try.

The MiniMax H3 bonus requires H3 as the core model. Public media must be lawful.
The operator is responsible for source authority, permissions, required consent,
and third-party/model licenses; RecastRoom records an attestation but cannot
verify them.

## Target categories

- Best Overall: $10,000
- Most Viral: RTX 5090
- Most Innovative: RTX 5090
- Open Weights Only: RTX 5090
- MiniMax H3 bonus: $1,000 in API credits

## Demo rule

The public demo must not use the private film/TV clips used during development. Record or generate an original/synthetic source clip, retain permission records, and obtain explicit consent from every identifiable performer where required.
